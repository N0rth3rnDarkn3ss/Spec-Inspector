
       Spec-Inspector

A lightweight, cross-platform command-line utility built with C# 
and .NET to display basic information on the system's hardware
(CPU, GPU, Memory, SSD/HDD, etc.)

This tool allows the users to gain more information about the
hardware their system's have. Mainly for use on portable devices
such as laptops that will not display the full hardware (Macbooks
as an example). Uses the latest .NET framework, .NET 10.0. There are no dependencies, no need to install .NET 
to run as the program is fully self-contained.

    How to run by Operating System


       Windows

1. Open your terminal (Command Prompt or PowerShell)
2. Navigate to the folder containing the file
3. Run the executable (Paste pathname into terminal or double-click .exe)

Example: C:\Users\User Here\Downloads\win-x64\Spec-Inspector.exe

        MacOS

1. Open Terminal
2. Navigate to folder (Paste pathname to FOLDER, not file)

Example: cd ~/Downloads/osx-arm64

3. Unlock executable file rights (Paste command below into Terminal)

chmod +x Spec-Inspector

4. Clear Apple Gatekeeper warning (Paste command below into Terminal)

xattr -d com.apple.quarantine Spec-Inspector

5. Launch tool (Paste FILE pathname into Terminal)

Example: ~/Downloads/osx-arm64/Spec-Inspector

        Linux

1. Open your system Terminal
2. Navigate to the FOLDER containing file (cd [pathname here])

Example: ~/Downloads/linux-x64

3. Apply terminal execution permissions (Paste command below into Terminal)

chmod +x Spec-Inspector

4. Launch tool (Paste FILE pathname into Terminal)

Example: ~/Downloads/linux-x64/Spec-Inspector
